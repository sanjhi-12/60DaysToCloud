# 10 Forks, Pull Requests and Issues

## What is a Fork?

A fork is a personal copy of another repository.

---

## What is a Pull Request?

A Pull Request is a request to merge changes into a repository.

---

## What is Code Review?

Code Review is the process of reviewing code before merging.

---

## What are Issues?

Issues are used to track bugs, tasks, and feature requests.

---

## Open Source Workflow

