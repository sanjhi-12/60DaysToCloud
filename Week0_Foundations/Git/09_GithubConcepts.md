# 09 GitHub Concepts

## What is GitHub?

GitHub is a cloud platform for hosting Git repositories.

---

## Repository Visibility

### Public Repository

Visible to everyone.

### Private Repository

Restricted access.

---

## README.md

Homepage of a repository.

---

## Star

Bookmarks repositories.

---

## Watch

Receives notifications.

---

## Fork

Creates a personal copy of a repository.

---

## Issues

Used to report bugs and request features.

---

## Releases

Represent software versions.

## Interview Questions

### What is GitHub?

GitHub is a cloud platform for hosting Git repositories.

### Difference between Star and Fork?

Star bookmarks repositories, while Fork creates a copy.

### What are Issues?

Issues are used to track bugs and improvements.

### What is README.md?

README.md is the homepage and documentation of a repository.

---

## Key Takeaways

- GitHub hosts repositories.
- README.md documents projects.
- Fork is used in open source.
- Issues track work.
- Releases represent versions.
